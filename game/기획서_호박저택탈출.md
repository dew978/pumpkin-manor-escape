# 호박 저택 탈출 — 게임 기획서 v0.2

> v0.1(순한 추격, 한 기기 2인, 조각마다 문제)에서 방향을 바꿨다.
> **진짜 술래잡기 + 각자 기기 온라인 협동 + 조각을 모아 문제 하나를 완성**하는 구조.

---

## 0. 한 줄 요약

친구들과 각자 기기로 저택에 들어가, 손전등 하나로 어둠을 비추며 괴물을 피해 **찢어진 쪽지 4조각**을 모은다.
조각을 순서대로 이어 붙이면 문제가 나오고, 정답을 넣어야 탈출문이 열린다. 잡히면 쪽지를 빼앗기고 새장에 갇힌다.

## 1. v0.1에서 바뀐 점

| 항목 | v0.1 | v0.2 |

| 잡혔을 때 | 입구로 돌아감 | **쪽지 1조각을 빼앗겨 다른 곳에 다시 숨겨짐** + 협동: 새장에 갇힘(친구가 1.5초 곁에 서면 구출) / 혼자: 시작 위치 + 시간 −15초 |

| 시야 | 넓은 직교 쿼터뷰 | 가까운 원근 쿼터뷰 + 손전등 원뿔 + 짙은 안개. 괴물은 어둠 속 빨간 눈으로만 보임 |
| 시간 | 0초가 되어도 +60초 | 0초 = 자정의 종 = 실패(그 층 다시 도전) |
| 그래픽 | 도형 조합 | Scenario 3D Collection의 GLB 28개 + 벽지·마루·돌·산울타리 텍스처 + 블룸 + 그림자 |

## 2. 핵심 루프 (층 하나 = 6~7분)

```
시작(현관) → 손전등으로 탐색 → 쪽지 조각 줍기(4개) ─┐
      ↑            괴물 발견 → 도망 / 옷장 숨기 / 아이템   │
      │            잡힘 → 조각 빼앗김 + 새장 → 친구가 구출  │
   다음 층 ← 탈출문으로 모두 나감 ← 정답 입력 ← 쪽지 순서 맞추기
```

- **쪽지(Tab)는 게임을 멈추지 않는다.** 풀이 중에도 괴물이 온다 → 옷장에 숨어서 풀거나, 친구가 망을 봐 준다.
- 새장에 갇힌 친구도 쪽지를 풀 수 있다 → 잡혀도 할 일이 있다.
- 오답은 시간 −10초, 두 번 틀리면 힌트.

## 3. 시스템

### 3-1. 괴물

| 괴물 | 등장 | 성격 | 대처 |
|---|---|---|---|
| 저승사자 | 1층·정원 | 시야 원뿔 + 가까우면 발소리를 들음. 쫓을수록 빨라짐(최대 +15%) | 모퉁이를 돌아 시야를 끊고 숨기 |
| 해골 기사 | 지하 | 조금 느리지만 시야가 넓음. 발견하면 소리쳐 근처 괴물을 부름 | 멀리서 먼저 보고 피하기 |
| 박쥐 악마 | 1층·정원 | 벽 위로 날아다님. 잡지는 않지만 비명으로 괴물을 부름 | 박쥐가 보이면 그 자리를 떠나기 |
| 거미 | 지하 | 숨어 있다가 0.5초 멈칫한 뒤 직선 돌진, 그 뒤 쉼 | 멈칫할 때 옆으로 피하기 |
| 까마귀 박사 | 정원 | 가장 멀리 봄 | 무덤·나무 뒤로 다니기 |

- 옷장에 숨으면 괴물이 못 찾는다. 단, **숨는 걸 본 괴물은 옷장을 연다.** 옷장은 최대 12초.
- 괴물이 쫓아오면 화면 가장자리가 붉어지고 심장 소리가 빨라진다.

### 3-2. 아이템 (한 사람 한 칸)

## 4. 교육 요소

- 문제는 **조각을 모두 모아야 읽을 수 있다** → 문장을 끝까지 읽는 습관.
- 순서 맞추기는 가장자리 색이 단서지만 문장의 흐름으로도 맞출 수 있다.
- 선생님이 층마다 문제를 바꾼다(JSON). 함께 할 때는 방장 기기의 문제로 모두 푼다.
- 결과 화면: 걸린 시간, 잡힌 횟수, 빼앗긴 쪽지, 틀린 답, 쓴 아이템.

## 5. 스토리 틀

- 층마다 일기장 한 장 → 마지막에 이름과 친구들을 기억해 낸다.

## 6. 기술

- three.js r160(vendor), ES 모듈, 설치 없음. 정적 호스팅(GitHub Pages)으로 배포.
- 방장 기기가 판정(30Hz), 친구 기기는 자기 위치를 보내고(15Hz) 상태를 받는다(12Hz).
- 모델 1.2GB 원본 → 8.8MB (삼각형 1,500~10,000개, 텍스처 256~512px).
- 그래픽 "가볍게": 블룸·그림자 끔, 해상도 1배.
- 아티팩트(claude.ai)에서는 WebRTC가 막혀 있어 온라인 협동이 안 된다 → GitHub Pages 같은 일반 호스팅 필요.

## 8. v0.3 추가 (2026-10-27)

### 이야기와 만화
- **도입:** 학교 할로윈 축제의 6학년 귀신의 집 → 맨 끝의 진짜 나무문 → 호박 저택으로 빨려 들어감 → 꼬마 유령 루미가 규칙을 알려 줌(쪽지 4조각·정답·자정·괴물·새장·옷장·구출) → 손전등을 받고 출발. 넘기는 컷 만화 7컷.

- **엔딩(반전):** 쪽지를 찢은 건 루미, 루미가 저택 주인. 백 년 동안 혼자였던 할로윈. 학교 강당에서 깨어나고 주머니에 "내년에도 같이 놀자" 초대장. 4컷.

## 9. v0.4 다듬기 (2026-10-27)

### 타이틀과 시작 흐름
- 타이틀: 어두운 보라 바탕에 호박빛 제목 하나, 잔잔한 타이틀 음악. 버튼은 **시작하기 · 설정 · 전체 화면** 셋만. 아래에 "삼대 710 제작"과 "© 2026 삼대710. 교실 내 비영리 사용 외 복제·수정·상업적 이용 금지".
- 시작하기 → **학년 고르기(1~6)** → 혼자 / 방 만들기 / 들어가기(분장 고르기) → 도입 만화 → 1층.
- 설정: 괴물 세기(학년에 맞게·느림·보통·빠름), 그래픽(고급·가볍게), 소리, 조작 안내, 선생님 문제 바꾸기, 만든 재료.

### 문제
- 학년별 기본 문제 10개씩(1~6학년) + 할로윈 상식 14개(난이도 lv 1~3).
- 층 문제 3개와 호박 상자 문제를 **고른 학년 문제 + 할로윈 상식**에서 섞어 뽑는다(판마다 1~2개는 할로윈).
- 정답 입력 대신 **보기 4개 고르기**. 1~2학년은 쪽지 조각에 순서 번호. 한 번 틀리면 힌트, 틀리면 시간 5초(느림)/10초 감소.

### 게임성 (할로윈 분위기)
- **호박 상자**: 문제를 맞히면 수정구·날쌘 물약 또는 시간 +20초.
- **사탕 12개**와 **별점 3개**(탈출 · 시간 1/3 남김 · 사탕 60%): 다 못 모아도 깰 수 있는 덤 목표.
- 벽가의 잭오랜턴(층마다 최대 14개), 길잡이 화살표(가장 가까운 쪽지 → 탈출문).

### 태블릿·초등학생 기준 난이도
- 지도 36×25로 넓히고 통로 2칸 이상, 방 사이 문 3칸. 소품 사이도 띄웠다. 몸 충돌 반지름 0.24.
- 손전등 범위 15·밝기 올림, 내 주변 빛(반경 3.6), 안개 살짝 옅게.
- 괴물: 쫓는 속도가 아이보다 느리다(최대 2.8 < 아이 3.4). 오래 쫓으면 지쳐서 쉬고(느림 7초), 잡은 뒤엔 쉬면서 그 아이를 8초 못 본 척. 시작 후 6초 이상 가만히 있다. 느림에서는 거미 없음, 쪽지 안 뺏음.
- 조이스틱: 화면 왼쪽 아무 데나 누른 곳에 생긴다.
- 고친 버그: 잡은 뒤 괴물이 쉬는 상태로 굳어 길을 막던 문제.

## 10. v0.5 사탕으로 괴물 꾀기 (2026-10-27)

- 사탕은 이제 **던지는 도구**다. 주운 사탕은 각자 가진다(층이 바뀌면 0개부터).
- 조작은 미니 유물레이더스 공격 단추와 같다: 오른쪽 아래 사탕 단추를 **끌어 겨누고 떼면** 던지고, **짧게 누르면** 가까운 괴물(쫓아오는 괴물 먼저)을 골라 그 괴물이 냄새 맡는 범위 안에서 나와 가장 먼 곳에 던진다. PC는 마우스로 겨누고 왼쪽 단추, F는 자동.
- 겨누는 동안 바닥에 선, 떨어질 자리 고리, 괴물이 냄새 맡는 범위(반지름 6칸)가 보인다.
- 사탕은 포물선으로 벽·가구를 넘어 최대 7칸 날아간다. 떨어질 자리가 막혀 있으면 가장 가까운 바닥에 떨어진다.
- 떨어진 곳에서 6칸 안의 괴물(돌진 중인 거미·눈먼 괴물 빼고)은 쫓던 것을 멈추고 사탕으로 간다(머리 위 "사탕!"). 가는 동안에는 학생을 잡지 않는다. 도착하면 4.5초 동안 먹고("냠냠") 다시 돌아다닌다.
- 별점의 사탕 조건은 그대로 "주운 수"로 센다(던져도 손해가 없다).
- 수정구 모델을 매끈한 유리 공(보랏빛 소용돌이, 금빛 받침)으로 바꿨다. 모델 파일 없이 코드로 만든다.
- 사탕 그림을 3D 화풍으로 다시 그렸다(`assets/sprites/candy.png`).

봇 점검(층마다 12판, 쫓기면 사탕을 짧게 눌러 던짐): 느림·보통 모두 36판 중 36판 탈출. 던지면 도망 시간이 줄었다(예: 보통 묘지 정원 11.3초 → 6.9초, 잡힘 2.4 → 1.3회).

## 11. v0.6 쪽지 대사창과 끌어다 놓기 (2026-10-27)

- **대사창:** 쪽지 조각을 주울 때마다 화면 아래에 얼굴 그림과 대사가 뜬다. 주운 아이(분장 얼굴)가 쪽지에 적힌 글을 그대로 읽고("찾았다! 찢어진 쪽지에 "0.3"라고 쓰여 있어."), 이어서 루미가 말한다.
  - 루미 대사는 층마다 조각 1~4번째로 다르다. 1층은 조작 안내(사탕 던지기, 쪽지 붙이기), 지하는 루미의 과거 복선, 정원은 "쪽지를 누가 찢었을까?" 반전 예고.
  - 게임은 멈추지 않는다. 글자는 한 자씩 찍히고, 읽을 시간이 지나거나 누르면 다음 대사. 함께 할 때는 모두에게 같은 대사가 뜬다.
- **끌어다 놓기:** 순서 맞추기는 조각을 끌어다 칸에 놓는다. 놓인 조각을 다른 칸으로 끌면 서로 바뀌고, 아래로 끌면 빠진다. 짧게 누르면 빈 칸 맨 앞에 들어가고, 놓인 조각을 짧게 누르면 빠진다. 네 칸이 차면 "이대로 붙이기"로 확인한다. 틀려도 조각은 그대로 남아서 바꿔 보기만 하면 된다.

### 손전등 (2026-10-27)
- 손전등을 더 밝고 좁게, 더 멀리 비추게 했다(빛 각도 0.78 → 0.46, 거리 15 → 20, 밝기 62 → 120). 바닥에는 앞으로 곧게 뻗는 빛줄기 판을 하나 깔고 벽에서 끊는다(가볍게에서도 보인다).

### 정답 연출·아이템 줍기·으스스한 소리 (2026-10-27)
- **정답:** 쪽지에 빨간 "정답!" 도장과 정답이 1.4초 뜬 뒤 쪽지가 닫히고, **탈출문 열리는 장면**(약 3.4초)이 나온다. 위아래 검은 띠, 카메라가 탈출문으로 천천히 이동, 문이 학생 쪽으로 삐걱 열리며(creak + gate 소리) 문틈에서 따뜻한 빛이 쏟아지고 "탈출문이 열린다!" 글이 뜬다. 장면 동안은 움직일 수 없고, 대신 모두 4초 동안 잡히지 않는다.
- **아이템 줍기:** 모래시계·수정구·날쌘 물약은 지나가면 줍지 않고, 가까이 가면 뜨는 상호작용 단추("🔮 수정구 줍기 E", 터치 기기는 "터치")로 줍는다. 손에 다른 아이템이 있으면 "바꾸기"가 되어 들고 있던 것을 그 자리에 내려놓는다. 사탕은 그대로 지나가면 줍는다.
- **으스스한 소리:** 게임 중 25~50초마다 마녀 웃음·늑대 울음·부엉이 중 하나가 왼쪽이나 오른쪽 멀리서 작게 들린다(정원은 늑대·부엉이, 저택 안은 마녀 웃음이 더 자주). Stable Audio 3로 만들었다(`art/audio_src`).

## 13. v0.8 가구 뒤지기 문제 · 문제 은행 늘림 (2026-10-27)

- **가구 뒤지기 문제:** 1초 가만히 뒤지기 대신, 호박 상자처럼 문제를 맞혀야 뒤진다. 문제 창 제목은 "🛢️ 나무통 뒤지기"처럼 가구 이름.
- **틀리면:** 그 가구가 6초 동안 잠긴다(모두에게 똑같이, 물음표 대신 🔒, 단추는 "🔒 n초 뒤에 다시"). 정답과 힌트를 보여 주고, 다시 오면 다음 문제가 나온다.
- **몸 숙이기:** 가구 문제를 푸는 동안은 괴물이 보는 거리가 절반이 된다. 움직이거나 창을 닫으면 풀린다. 너무 멀어지면(2칸 넘게) 창이 닫히고, 다른 친구가 먼저 열면 "다른 친구가 먼저 열었어요".
- **빼앗긴 조각:** 문제를 풀어야 하므로 가장 먼 꽝 가구가 아니라 남은 꽝 가구 중 아무 곳에 다시 숨는다.
- **문제 은행:** 학년별 10문제 → 30문제, 할로윈 상식 14문제 → 42문제(쉬움·보통·어려움 14개씩). 모두 222문제.
- **문제 나누기:** 판마다 층 문제 3개를 뽑고, 남은 문제를 섞어 층마다 18문제(호박 상자 5 + 가구 13)씩 나눠 준다. 같은 층 안에서는 겹치지 않고, 은행이 모자라면 다시 섞어 잇는다(1~2학년은 3층에서 일부가 다시 나올 수 있음).
- 선생님이 설정에서 바꾼 문제 은행을 이 기기에 저장해 두었다면 그 은행을 그대로 쓴다(새 기본 문제를 쓰려면 문제 편집에서 "기본 문제로" → "저장").

봇 점검(가구마다 문제를 4~8초 읽고 75%로 맞힘, 괴물이 쫓아오면 문제를 버리고 도망, 층마다 12판): 느림 36/36, 보통 35/36 탈출(묘지 정원 1판 시간 초과). 한 층 144~212초, 가구 6~9곳을 뒤지고 2~3번 틀렸다.

- 그보다 뒤 단원 문제 44개를 뺐다(예: 2학년 m·cm와 시각과 시간, 3학년 들이와 무게·자석, 4학년 사각형·다각형·꺾은선그래프·소수, 5학년 소수의 곱셈·직육면체·평균·태양계, 6학년 원의 넓이·비례식·원기둥).
- 학년마다 30문제 → 45문제(국어·수학·과학·사회·통합). 할로윈 42문제 그대로, 모두 312문제.
- 산수 문제 만들기도 맞췄다: 1학년은 받아올림 없는 덧셈·뺄셈과 10개씩 묶음, 3학년에 (세 자리)×(한 자리)·나머지 있는 나눗셈, 4학년에 분수 뺄셈, 5학년은 소수의 곱셈 대신 분수×자연수·어림하기·혼합 계산, 6학년은 비례식 대신 분수÷분수·소수÷자연수. 수를 읽은 끝소리에 맞춰 조사(을/를, 은/는)를 붙인다.

봇 점검(층마다 12판): 느림 72판 중 71판, 보통 72판 중 65판 탈출, 6층을 다 깨는 데 봇 기준 약 48~57분.


## 17. v1.2 층마다 쪽지 한 장 · 오른손 단추 (2026-10-28)

- **쪽지는 층마다 한 장으로 되돌림:** 쪽지를 두세 번 찾는 것이 헷갈렸다(같은 '쪽지'를 또 찾는 것처럼 보임). 층마다 4조각을 모아 이어 붙여 문제 하나를 풀면 바로 탈출문이 열린다.
  쪽지 여러 장을 쓰는 코드(round, 다음 쪽지)는 그대로 두고 층 설정에서 notes를 뺐다(기본 1장). 다시 여러 장으로 하려면 A·B 쪽지처럼 이름을 나눠 보여 줘야 한다.
- **시간:** 모든 층 480초. 층 시작 안내·루미 대사에서 '쪽지 n장' 말을 뺐고, 왼쪽 위 '쪽지 1 / 1장'도 한 장일 때는 숨긴다.
- **오른손 단추:** 쪽지·아이템 단추를 왼쪽 아래에서 사탕 단추 바로 왼쪽으로 옮기고 92px 정사각 단추로 키웠다(태블릿에서 왼손은 이동, 오른손은 단추). 상호작용 단추는 그 왼쪽, 소리 단추만 왼쪽 아래에 남김. 루미 대사창은 단추와 겹치지 않게 20px 올림.

봇 점검(층마다 12판): 느림 72판 중 71판, 보통 72판 중 66판쯤 탈출. 6층을 다 깨는 데 봇 기준 약 16~19분(만화·대사 제외).
